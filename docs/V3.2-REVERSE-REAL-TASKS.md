## Task 5: 本地低风险 pentest 真实任务

路由：`routing.md` -> `pentest-tools/SKILL.md`

样本：本地 SQLite demo 靶场 `127.0.0.1:18080`

执行命令：

```bash
nmap -sV -p 18080 127.0.0.1
ffuf -u http://127.0.0.1:18080/FUZZ -w ffuf-wordlist.txt -mc all -fs 10
nuclei -duc -t reverse-skill-local-nuclei.yaml -u http://127.0.0.1:18080
sqlmap -u 'http://127.0.0.1:18080/items?id=1' --batch --level=1 --risk=1 --threads=1 --smart
```

结果：

- `nmap`：识别 `18080/tcp open`
- `ffuf`：爆出 `robots.txt`、`admin`、`secret.txt`、`items`
- `nuclei`：命中 `reverse-skill-local-health`
- `sqlmap`：确认 `GET id` 可注入，识别出
  - boolean-based blind
  - time-based blind
  - UNION query
  - back-end DBMS: `SQLite`

结论：

- `v3.2` 中的 pentest 工具链不是“有路径没执行”，而是能对本地低风险目标完成真实闭环
